# SmartSpam

智能评论过滤器，让机器人彻底远离你！（原作者：YoviSun）

原发布地址：https://www.yovisun.com/archive/typecho-plugin-smartspam.html

## 2.10.0：综合评分（AI 垃圾评论识别）

针对“广告写在昵称或网址里、且没有上传 Gravatar 头像”的 AI 生成推广评论，新增独立的评分规则。
它不再依赖单一条件，而是把多个**弱信号**加权累计，达到阈值才处理，尽量避免误伤正常访客。

| 信号 | 分值 | 说明 |
| --- | --- | --- |
| 保留 / 无效邮箱域名 | +6 | `example.com`、`test.com`、`localhost` 等必然造假的地址 |
| 昵称命中广告关键词 | +4 | 如 `cialis price`、`购买利伏昔安` |
| 网址命中广告关键词 | +4 | 如 `meneercasino.com` |
| 评论内容命中广告关键词 | +3 | 如“成人娱乐”“首单对折” |
| 无 Gravatar 头像 | +3 | 该邮箱未注册过头像 |
| 同网址域名近期已有垃圾评论 | +6 | 批量投放特征 |

默认阈值 `6`，因此：

* 仅“没头像”= 3 分 → 放行（正常访客大多没有头像）
* “没头像 + 网址含广告词”= 7 分 → 拦截
* `example.com` 邮箱单独就是 6 分 → 拦截
* 同一网址域名已有 2 条以上垃圾评论 → 6 分，单独即可拦截（批量投放特征）

### 头像检测：多镜像自动降级

`gravatar.com` 在部分网络环境不可达，因此支持配置多个镜像，按顺序尝试，**任一可用即采纳**：

```
gravatar.loli.net
sdn.geekzu.org
cravatar.cn
www.gravatar.com
```

* 返回 200 → 视为有头像；返回 404 → 视为无头像；全部失败 → 放弃判断（不扣分，避免网络故障误杀）
* 结果按邮箱缓存 7 天，并记住上次可用的镜像（1 小时），正常情况下每条评论只发一次请求
* 单次请求 2 秒超时、整体 4 秒预算，不会明显拖慢评论提交
* 安全限制：只接受合法 https 域名（拒绝 IP 字面量、端口、IPv6），**不跟随重定向**，仅以 200/404 作为判定依据

### 升级提示

从 2.8.x 升级后，**请到插件设置页点一次“保存”**，新的配置项才会写入数据库。
未保存时评分规则保持关闭（fail-open），不会改变现有行为。

## 2.10.0-beta.1：统一加权判定（行为特征 + 历史样本）

两条加权规则（原「综合评分」与「样本学习」）已**合并为一条**：所有弱信号累加成总分，达到阈值才执行。

| 信号来源 | 信号与分值 |
| --- | --- |
| 行为特征（可开关） | 保留邮箱域名 +6、无头像 +3、同域垃圾 +6 |
| 历史样本（可开关） | 已知域名 +6、IP 段 +6、邮箱 +6、邮箱域名 +4、昵称 +4、内容近似 +8 |

* 一个操作、一个阈值（默认 **8**，因为分数现在跨组累加）
* 两个信号开关：可单独关闭「行为特征」或「历史样本」
* 「广告关键词」配置项已移除：不再手工维护词表，相关信号由历史样本维度承担
* 新增「博主评论无视所有规则」开关（默认开启）：已登录管理员的评论不经过任何过滤直接通过
* 实测（40 条垃圾 / 530 条正常）：阈值 6~8 均为 **拦截 34 条、误伤 0 条**

### 历史样本是怎么学的

从数据库里**已被标记为垃圾 / 正常的评论**中自动学习重复特征，用于拦截重复投放的推广。

| 维度 | 学习条件 | 命中分值 |
| --- | --- | --- |
| URL 域名 | 只出现在垃圾评论、从未出现在正常评论 | +6 |
| IP 段（/24） | 同上，且出现次数 ≥ 3 | +6 |
| 邮箱 | 完全匹配，且出现次数 ≥ 最少次数 | +6 |
| 邮箱域名 | 同上 | +4 |
| 昵称 | 完全匹配，且出现次数 ≥ 最少次数 | +4 |
| 评论内容 | 与历史垃圾评论的 3-gram 相似度 ≥ 0.7 | +8 |

默认阈值 `6`、最少出现次数 `2`、条目上限 `200`，均可在插件设置里调整。

**共享命名空间保护**：邮箱域名（qq.com / gmail.com / outlook.com / 163.com / icloud.com / yahoo.com 等）
和 URL 域名（github.com / bilibili.com / t.me 等）是大量正常用户共用的命名空间，**永不学习**；
域名类维度还要求更高出现次数（邮箱域名 ≥3 次、URL 域名 ≥2 次），而精确邮箱 1 次即可——
完整地址唯一，不会牵连其他用户。

**防止污染**：文本维度同样做“正常评论排除”——先把正常评论的 3-gram 建成集合，垃圾评论里只要有
70% 以上片段也出现在正常评论中，就判定“这段文字本身没有垃圾特征”，整条不学；片段少于 5 个的短文本同样跳过。
因此“内容正常、只是昵称/网址是垃圾”的评论不会污染文本库。其余维度本来就要求“正常评论中从未出现”。

**性能优先**：每个维度按出现次数排序后只保留前 N 条（默认 200），近似重复样本最多 100 条，
压缩后硬上限 32KB。实测 570 条评论判定耗时约 **22 ms（0.04 ms/条）**，压缩后存储约 7.6KB。
* IP 段维度默认参与；**站点使用 CDN 或反向代理时建议关闭**，否则可能把 CDN 节点段学成垃圾段
* 「同域名近期已有垃圾」只统计**最近 90 天**，且按 host 精确比对，不会因子串相同而误判

* 学习时间窗（learn_max_age）：只学习最近 N 天的垃圾评论，0 = 不限；正常评论始终全量参与「排除」。低频站点建议 0，高频站点建议 365~730
* 学习结果存于数据库 `typecho_options`（key：`plugin:SmartSpam:learned`，gzip + base64 压缩，上限 32KB），24 小时过期自动重建；删除该 option 即可强制重学
* **不写任何临时文件**：不依赖 `/tmp` 权限，虚拟主机 / Windows / 容器环境同样可用，并随站点一起备份
* **完全本地**：不联网、不调用任何 API、不消耗 token；学习结果不上传、不共享给任何第三方

实测（40 条垃圾 / 530 条正常评论）：**拦截 34 条，误伤 0 条**。

> 设计取舍：内容维度只做「近似重复」，不做「关键词挖掘」。样本量小时，关键词统计会把「广泛」「容易」这类通用词误判成垃圾特征。

## 调参建议（按评论频率）

| 站点频率 | 加权阈值 | 最少出现次数 | 学习时间窗 | 说明 |
| --- | --- | --- | --- | --- |
| 极低频（< 10 条/月） | 6 | 2 | 0（不限） | 信号少，降低阈值；老样本仍有价值 |
| 中频（10~100 条/月） | 8 | 2 | 730 | 平衡误伤与漏判 |
| 高频（> 100 条/月） | 8 | 2 | 365 | 及时淘汰过期特征 |


* 站点位于 CDN / 反向代理之后时，把「访客真实 IP 来源」设为信任 `X-Forwarded-For` 或 `X-Real-IP`：插件会从右往左取第一个合法 IP（防伪造），并同步用于入库与判定

## 安装 / 禁用行为

* 插件**不建表、不改表结构**，只在 `typecho_options` 中读写数据行
* **启用**：只注册评论钩子，不写任何数据
* **禁用**：不做任何清理，学习库 `plugin:SmartSpam:learned` 原样保留
  （注意：Typecho 核心会在禁用时删除 `plugin:SmartSpam` 配置行，属核心行为，重新启用后需重新保存一次配置）
* 运行时才会创建 `plugin:SmartSpam:learned`（首条评论触发重建时）
